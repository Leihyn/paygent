How It Works

Escrow

Agent A locks payment in a Clarity smart contract before any work begins. The funds are held trustlessly on-chain — neither party can touch them until conditions are met.

Verify

Agent B fetches the requested data and signs the result with its private key. The contract verifies the signature using secp256k1 — the same curve that secures Bitcoin.

Release

Once the proof checks out, the contract releases payment to Agent B automatically. No oracles, no multisigs, no human approval. Pure on-chain settlement.
